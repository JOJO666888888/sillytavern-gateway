🐦 飞书 -
长连接模式，无需公网 IP。需先在项目根执行 npm install @larksuiteoapi/node-sdk。详见 docs/ADDING_PLATFORMS.md
🐧 QQ官方 -
腾讯官方机器人（≠ OneBot）。需先执行 npm install qq-official-bot。群/频道消息由 @ 触发；回复有 5 分钟被动窗口。详见 docs/ADDING_PLATFORMS.md
🔔 钉钉 -
Stream 长连接模式，无需公网 IP。需先执行 npm install dingtalk-stream。回复走会话临时地址，约 1.5 小时窗口。详见 docs/ADDING_PLATFORMS.md
自建推理管线 -
开启后网关自己组装 prompt 并调用 LLM，无需一直开着 SillyTavern 页面；每个会话可独立绑定角色卡/预设/世界书/存档。
保存后需重启网关服务才能切换启用状态。
