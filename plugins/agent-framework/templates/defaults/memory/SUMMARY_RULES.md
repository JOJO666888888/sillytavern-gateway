# 自动摘要规则

> 本文件定义 Agent 自动生成剧情摘要的规则，供 memory-engine 与 agent-rp 的自动摘要流程参考。
> 不直接注入 prompt（避免占用 token），仅作为运行时配置。

## 触发条件

- 每 N 轮自动生成一次摘要（N 由配置项 `summaryInterval` 决定，默认 10）
- N=0 表示禁用自动摘要
- 也可由用户手动触发（如 `/rp summary` 命令，若实现）

## 摘要格式

摘要应包含以下结构（不超过 300 字）：

```
【当前进度】一句话概括当前剧情所处的阶段
【关键事件】本轮 N 轮内发生的 2-3 个关键事件（按时间顺序）
【关系变化】角色关系的显著变化（如有）
【下一阶段】下一阶段可能的方向（1-2 条）
```

## 归档规则

- 自动摘要写入 `memory/project.md`，覆盖旧的"当前章节/已完成事件"部分
- 保留"伏笔清单"部分（不覆盖，仅追加回收状态）
- 每 50 轮将 project.md 的历史部分归档到 `memory/archive/project-{章节名}.md`（若实现）
- 归档后 project.md 只保留最近的内容，避免文件膨胀

## 摘要质量要求

- 客观记录，不带评价
- 具体到事件，不写"发生了一些事"
- 保留关键细节（谁、做了什么、为什么），删除过程描写
- 不 invent 没发生过的事
