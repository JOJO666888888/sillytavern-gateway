# 参考信息索引

> 本文件记录关键资产的位置索引，方便 Agent 用 file.read 按需查阅。
> 几乎不变，仅在资产增减时更新。

## 角色卡

- 主角：`assets/characters/<角色卡名>.json`
- NPC：`assets/characters/<角色卡名>.json`

## 世界书

- `assets/worldbooks/<世界书名>.json`

## 文风

- 默认文风：`styles/default.md`
- 其他文风：`styles/<文风名>.md`

## Skill

- 已加载的 skill 列表见 session.loadedSkills
- skill 文件位于：`skills/<skill名>.md`

## 记忆文件

- 剧情进度：`memory/project.md`
- 用户偏好：`memory/feedback.md`
- 用户设定：`memory/user.md`
- 参考索引：`memory/reference.md`（本文件）
