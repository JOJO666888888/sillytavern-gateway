# 趣味群聊抢答 RP 插件 (group-rp-bidding)

SillyTavern Gateway 插件 -- 群聊场景下的多人抢答角色扮演。

## 玩法说明

```
AI 叙述剧情（含结束标记【本轮结束】）
        │
        ▼
  插件检测到标记，开启抢答窗口（30秒倒计时）
        │
        ▼
  群成员抢答 ── 第一个有效抢答者胜出
        │
        ▼
  胜者内容自动转发给 SillyTavern ──> AI 生成下一轮剧情
        │
        ▼
    循环 ↩
```

## 安装

将 `group-rp-bidding/` 目录放入网关的 `plugins/` 文件夹：

```
plugins/
└── group-rp-bidding/
    ├── plugin.json
    ├── index.js
    └── README.md
```

重启网关，或调用 `POST /api/plugins/group-rp-bidding/reload` 热加载。

## 配置

在网关面板的插件配置区，或通过 API 修改：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `endMarker` | string | `【本轮结束】` | AI 输出中用于触发抢答的结束标记 |
| `bidTimeout` | number | `30` | 抢答超时时间（秒） |
| `implicitBid` | boolean | `true` | 抢答阶段内任意群消息是否视为抢答 |

### 如何配置结束标记

在 SillyTavern 预设的底部指令中，要求 AI 在每轮剧情叙述结束时输出该标记。例如在预设中加入：

```
每轮剧情叙述结束后，在最后一行输出 【本轮结束】
```

插件会自动检测此标记并开启抢答。标记不会显示给用户（插件会自动剥离）。

## 命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `/bid <内容>` | `/抢答 <内容>` | 显式抢答，提交行动内容 |
| `/skip` | `/跳过` | 跳过当前抢答轮次（超时后使用） |
| `/bstatus` | `/抢答状态` | 查看当前群的抢答状态 |
| `/breset` | `/抢答重置` | 强制重置抢答状态（卡死恢复） |

### 抢答方式

- **隐式抢答**（`implicitBid=true`，默认）：抢答窗口开启期间，直接发送任何消息即视为抢答，第一个发送的人胜出
- **显式抢答**（`implicitBid=false`）：必须使用 `/bid <内容>` 命令抢答

## 游戏流程示例

```
AI: 苏晚抬头看了你一眼，又低下头继续画画。
    雨声渐渐小了，咖啡馆里只剩下咖啡机的嗡嗡声。
    她似乎想说什么，但又忍住了……
    【本轮结束】

    🎮 ━━ 抢答开始 ━━
    ⏱️ 30秒内 直接发送你的行动，或使用 /bid <内容> 抢答
    最快抢答的玩家将推进剧情！

玩家A: 我轻轻问了一句"在画什么？"

🏆 抢答胜出: 玩家A
📝 行动内容: 我轻轻问了一句"在画什么？"
━━ 剧情推进中 ━━

AI: 苏晚的笔尖顿了一下，抬起头……
    （下一轮剧情）
    【本轮结束】
```

## 技术细节

- **会话隔离**：状态基于 `platform:chatId` 隔离，不同群组互不干扰
- **并发安全**：胜者判定采用同步原子操作（check -> set -> close），Node.js 单线程保证不被中断
- **防循环**：出站过滤器仅修改消息内容和设置状态，不调用 send/reply
- **资源清理**：onUnload 清理所有定时器和过滤器，防止内存泄漏
- **超时处理**：倒计时结束自动重置状态，提示 /skip 跳过

## 状态机

| 状态 | 说明 |
|------|------|
| `idle` | 空闲，等待 AI 叙述 |
| `bidding` | 抢答窗口已开启，等待玩家输入 |

状态转换：`idle --(检测到结束标记)--> bidding --(有人抢答/超时/skip)--> idle`
